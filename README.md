# Microcontroller-Project
__German:__
## Ziel und Motivation
Das Ziel dieses Projektes ist es ein Mathetrainer/Rechentrainer zu bauen.
Der Hintergrund und die Motivation für dieses Projekt ist der Verlust des Kurzzeitgedächtnisses und voranschreitende Demenz eines Senioren im nahen Bekanntenkreis.

## Planung
- Nutzung der ArduinoIDE 
- mit möglichen Komponenten vertraut machen
- Sketches anfertigen
- Schaltpläne erstellen
- Breadboard Prototyp erstellen
- PCB erstellen und handtauglichen Prototypen 
- Embedded System Verständnis vertiefen
  - Stärkerer Microcontroller
  - besser skalierbare Programmiersprache

## Komponenten 
- Arduino Nano Klon (ELEGOO Nano V3)
- LCD Display
- Taktiles Keypad
- weitere klassische Komponenten aus Einsteiger Kits
